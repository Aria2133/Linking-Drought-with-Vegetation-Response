# Data availability

| Category | What it includes | Where it is |
|---|---|---|
| **Public source datasets** | MODIS MOD13Q1, MOD09A1, MYD21C1, MOD17A2H, MCD12Q1; gridMET (SPEI-1, VPD); GRACE/GRACE-FO mascons; GOSIF; FLUXCOM GPP | Public, from the original providers. IDs and versions: [`../data_access/data_sources.csv`](../data_access/data_sources.csv). Not redistributed here. |
| **Code** | Earth Engine scripts, Python preprocessing, ecological analyses, forecasting models, figure and table scripts | This repository ([`../gee`](../gee), [`../src`](../src)) |
| **Methodological metadata** | hyperparameters, rolling-origin folds, random seeds, pixel-selection rule and exact counts, package versions | This repository ([`../config`](../config), [`../environment`](../environment)) |
| **Processed datasets generated by the authors** | land-type-masked monthly rasters, monthly land-type series, forecasting task caches, model predictions and metric tables | Not publicly deposited. Available from the corresponding author on reasonable request. They can be regenerated from the public sources with the code here. |
| **Derived spatial products** | NIRv percentage-change maps, severe-response masks, land-type masks | Not publicly deposited (same as above). |
| **Material not redistributed** | copies of third-party products (MODIS, gridMET, GRACE, GOSIF, FLUXCOM) | Must be obtained from the providers under their own terms. |

Suggested wording for the manuscript:

> All source datasets are publicly available from their providers (Supplementary Table / `data_access/data_sources.csv`).
> The code, Earth Engine scripts, model configurations, fold definitions, random seeds and pixel-selection tables are available at
> https://github.com/Aria2133/Linking-Drought-with-Vegetation-Response. Processed and derived datasets generated in this study
> (land-type-masked rasters, monthly series, model predictions and derived maps) are not publicly deposited and are available from
> the corresponding author upon reasonable request.
